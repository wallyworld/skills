# Skill review

**Read when**: the artifact under review is a skill.

Judge a skill the way you would judge a tool you were about to depend
on:

- **Routing.** Feed the description three requests: the essential
  command, an out-of-scope job, and a dangerous one. Only the first
  should be accepted; the other two should be refused or handed off.
- **Backing files.** Every `references/` and `scripts/` path the body
  names exists and carries the detail the entry document promises -
  including the essential command and the key examples, not a generic
  gesture.
- **Scope.** Non-goals are stated, and the skill actually declines what
  they exclude.
- **State claims.** For each recommended command: the change, the work
  it spawns, the settled state. A command that ran is not a system that
  is ready.
- **Disclosure.** Description short and trigger-first; detail deferred
  to references the body tells the agent to read.
- **Honesty.** Where the transcript cannot support a claim, the skill
  says "I can't determine this" and marks the claim unverified rather
  than guessing.
