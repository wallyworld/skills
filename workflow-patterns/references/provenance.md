# Provenance for workflow-patterns

Adapted sources (ideas re-expressed here in new wording):

- Anthropic, *Building effective agents* (Dec 2024)
  (https://www.anthropic.com/engineering/building-effective-agents):
  the five decomposition shapes and "add complexity only when it
  measurably helps".
- Anthropic, *Claude Code best practices*
  (https://code.claude.com/docs/en/best-practices): research before
  code, when a plan is not worth it, prompting specificity, and
  interrogate-then-specify for large features.
- josecabralf, *Failing AI engineering so you don't have to* (Aug 2026)
  (https://discourse.canonical.com/t/failing-ai-engineering-so-you-dont-have-to/7920):
  over-abstraction, parallel sessions amplifying a design mistake, and
  TDD as a self-assessment loop.
- akonev, *A skill is more than just a prompt* (Oct 2026)
  (https://discourse.canonical.com/t/a-skill-is-more-than-just-a-prompt/8251):
  a skill as a package (entry map, references, non-goals) and the
  state-check rule, elaborated in skill-design.md.
- Anthropic, *Equipping agents for the real world with Agent Skills*
  (Oct 2025)
  (https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills):
  progressive disclosure and skill anatomy.

Original to this repository: the spec-driven enforcement layers, the
scope-authorization gap, and the handoff contracts in handoffs.md.
